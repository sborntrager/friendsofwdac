# Index Working Revisions

These notes compare the current homepage in `index_working.html` against the visual direction established in the moodboard.

## Priority Revisions

1. Rebuild the hero as a story section, not just a banner.
   The moodboard hero has image, value chips, a north-star line, and a larger emotional statement. The current hero is still a standard text-over-photo block.

2. Add a true display typography layer.
   Keep `Inter` for body and UI text, but bring in a more expressive headline style for the hero and section titles instead of relying on `Montserrat` everywhere.

3. Break up the "single white shell full of cards" look.
   The homepage currently reads like one clean card system from top to bottom. Add at least one full-bleed or editorial band so the page has more rhythm and contrast.

4. Rework the homepage hierarchy so one action clearly wins.
   Right now the post-hero grid gives similar visual weight to almost everything. Feature `Donate` and `Become a Friend` first, then make exploration secondary.

5. Stop treating Docs like another photo tile.
   The moodboard separates home tiles from download cards. On the homepage, replace the Docs tile with a compact "popular downloads" shelf or a more utility-driven module.

6. Convert "Who we are" from a paragraph block into proof points.
   Pull out stats, impact chips, or a testimonial so visitors can scan the case for support quickly.

7. Use the imagery system more distinctly.
   Mix present-day pool life, archival history, and local civic imagery on the homepage instead of relying mostly on the exterior hero plus faded tiles.

8. Add visible photo credits anywhere featured imagery is used.
   The moodboard treats credits as part of the brand system, and that will make the site feel more intentional and trustworthy.

9. Add purposeful motion.
   A hero reveal, staggered tile entrances, and richer hover states would make the site feel more alive without becoming distracting.

10. Replace generic headings like "Start here" with more branded, action-forward copy.
    Options could include phrases like "Choose Your Way to Help" or "Why WDAC Matters Here."

## Overall Takeaway

The moodboard feels editorial, layered, and specific to WDAC. The homepage still feels like a clean prototype. The next round of revisions should focus on stronger visual hierarchy, more expressive typography, better use of the photo system, and a homepage structure that feels more memorable and less uniform.
