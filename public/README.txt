Favicon Package
===============

Generated from markLogo.png.

Included files:
- favicon.ico: multi-size ICO for legacy/browser compatibility
- favicon.svg: SVG favicon wrapper
- favicon-16x16.png / favicon-32x32.png / favicon-48x48.png / favicon-64x64.png / favicon-96x96.png / favicon-128x128.png / favicon-256x256.png / favicon-384x384.png
- apple-touch-icon.png: 180x180 iOS home screen icon
- android-chrome-192x192.png and android-chrome-512x512.png: PWA/Android icons
- maskable-icon-192x192.png and maskable-icon-512x512.png: Android adaptive/maskable icons
- mstile-150x150.png and browserconfig.xml: Microsoft tile support
- site.webmanifest: basic PWA manifest
- logo-transparent.png: transparent background source prepared from original logo
- html-head-tags.txt: paste-ready HTML <head> tags

Install:
1. Upload the image/icon files to your site root or public folder.
2. Paste the contents of html-head-tags.txt inside your page <head>.
3. Confirm site.webmanifest metadata matches the live site/app name.
