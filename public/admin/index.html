Imports and Exports Guide

How imports work

  1. Start with the downloaded CSV template for members or donors.
  2. Fill out one row per person and keep the header row unchanged.
  3. Click Upload members CSV or Upload donors CSV to save records and a batch snapshot.
  4. Use View import summary to review the most recent saved batches.

How exports work

  1. Click Download members CSV or Download donors CSV.
  2. The export includes the current saved records from the admin database.
  3. You can edit exported rows and re-upload them as a new import batch.

Current limitation: field mapping and duplicate review are still in progress, so keep uploaded files clean and template-based.

    Admin guide

    Use this quick guide for the core admin tasks.

    Daily workflow

    1. Click Refresh dashboard after signing in to load current records and mailbox status.
    2. Review new form submissions in Forms inbox and mark items that need follow-up.
    3. Use People, Members, and Donors panels to verify records and save updates.

    Email workflow

    1. Open the Email tab and click Refresh mailbox to load latest Zoho messages.
    2. Use New message to compose, or open a message and reply from the right panel.
    3. If mailbox status fails, click Reconnect Zoho and complete the Zoho login prompt.

    Imports / exports

    1. Download the CSV template first, then keep the header row unchanged.
    2. Upload members or donors CSV from Imports / Exports.
    3. Use View import summary to verify row counts and recent batches.

    If anything fails, use Contact support to send details directly from this page.
